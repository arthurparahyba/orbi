# @orbi/desktop

O app do Orbi: React (telas Conversa, Cérebro e Autonomia) dentro de uma janela
Tauri que inicia e encerra o runtime.

Da raiz: `npm run demo:ui` (no navegador, contra o `npm run demo`), `npm run dev`
(janela nativa) e `npm run build` (executável com o runtime embutido).

Veja [docs/arquitetura.md](../../docs/arquitetura.md) e
[docs/empacotamento.md](../../docs/empacotamento.md).
